# 🎯 Exercise: Create a Responsive Profile Card with Animations

Welcome to this hands-on exercise! Your task is to build a **responsive profile card** using **HTML** and **CSS**. This project will help you practice key web development skills, including layout design, animations, and responsive web design.

---

## 📋 Objectives

1. **Create a Profile Card**:
   - Display a profile image, name, job title, and a short description.
   - Include social media links (e.g., LinkedIn, GitHub, Twitter).

2. **Add Hover Animations**:
   - Scale the profile image slightly when the card is hovered.
   - Lift the entire card upward with a smooth transition.

3. **Ensure Responsiveness**:
   - Use **media queries** to make the card adapt to different screen sizes (desktop, tablet, mobile).
   - Ensure the layout remains clean and readable on all devices.

4. **Use Modern CSS Techniques**:
   - Use **Flexbox** for layout alignment.
   - Add **CSS transitions** for smooth animations.

---

## 🛠️ Requirements

### HTML Structure
- Use semantic HTML elements.
- Include:
  - A `div` container for the profile card.
  - An `img` tag for the profile image.
  - Headings (`h1`, `h2`) for the name and job title.
  - Paragraphs (`p`) for the description.
  - Anchor tags (`a`) for social media links.

### CSS Styling
- Style the card with a clean, modern design.
- Add a box shadow to give the card a "floating" effect.
- Use Flexbox to align elements within the card.
- Add hover effects:
  - Scale the profile image slightly.
  - Lift the card upward with a smooth transition.

### Responsive Design
- Use media queries to adjust the card's layout for smaller screens.
- Ensure the card is fully functional and visually appealing on mobile devices.

## 🚀 How to Get Started

1. **Set up your project**:
   - Create an `index.html` file for the structure.
   - Create a `styles.css` file for the styling.

2. **Build the HTML structure**:
   - Add the profile image, name, job title, description, and social links.

3. **Style the card**:
   - Use Flexbox for layout alignment.
   - Add hover animations and transitions.

4. **Make it responsive**:
   - Use media queries to adjust the layout for smaller screens.

5. **Test your work**:
   - Open the `index.html` file in your browser.
   - Resize the browser window to test responsiveness.
