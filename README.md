Exercise: Create a Responsive Profile Card with Animations
Objective:
Build a responsive profile card using HTML and CSS that includes:

A profile image, name, job title, and short description

Social media links (e.g., LinkedIn, GitHub, Twitter)

Hover animations: Scale the profile image and lift the card on hover

Responsive design: Ensure the card adapts to different screen sizes (desktop, tablet, mobile)

Requirements:
Use Flexbox for layout

Add CSS transitions for smooth animations

Use media queries to make the card responsive

Ensure the design is clean and modern
